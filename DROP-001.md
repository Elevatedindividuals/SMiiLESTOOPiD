# DROP 001 — Stoopid Smiley Launch

The first launch centers on STOOPID SMILEY — establish the hero character
and visual identity before introducing the rest of the squad.

## Products
1. **HERO HOODIE** — Oversized/relaxed hoodie featuring Stoopid Smiley,
   SMiiLESTOOPiD. branding and an associated saying.
2. **GRAPHIC TEE** — Wearable everyday introduction to Stoopid Smiley.
3. **SWEATSHIRT / CREW** — Simple character-forward graphic treatment.
4. **STICKER** — Inexpensive entry product; natural format for the mascot.
5. **ACCESSORIES** — Only if they strengthen the drop, never clutter.

## Established sayings
- SMiiLESTOOPiD.
- Smile.Stoopid.
- Do not disturb.
- Hood up.
- PeaceOut.
- "Only reasonable thought is SMiiLESTOOPiD."

Keep future sayings short, ownable, and compatible with the character wearing them.

## Priority order (from the master brief)
1. Lock Stoopid Smiley artwork
2. Lock Drop 001 sayings
3. Finalize hero hoodie
4. Finalize tee
5. Finalize supporting products
6. Prepare production-ready artwork
